# เว็บสร้าง Portfolio ส่วนตัว กรอกโปรไฟล์และผลงาน แล้วบันทึก/โหลดข้อมูล

1. เปิดWebด้วย : http://<public -ip>/ 
2. สร้างPortfolio 
   • กรอก Display name (บังคับใส่)<br>
   • What I enjoy / What I’ve tried / What I’m curious about: ใส่อะไรก็ได้<br>
   • กดปุ่มเขียว Create portfolio<br>
   • ชื่อจะโผล่ในกล่อง Portfolio people ด้านบน<br>
4. เลือก Portfolio
   • คลิกชื่อตัวเองในกล่อง Portfolio people ให้ปุ่มเป็นสีเขียวอ่อน ต้องเลือกก่อนถึงจะเพิ่ม Item ได้ <br>
5. เพิ่ม Item 
   • เลื่อนลงไปที่ Edit Portfolio Items<br>
   • กรอก Title, Role, Description, What I did, Challenge, Type, Date, Skills (คั่นด้วย comma เช่น HTML, CSS), What I learned, Next step, Evidence (ลิงก์ผลงาน)<br>
   • กดปุ่มเขียวล่างสุด Add Items<br>
   • การ์ด Item จะโผล่ในกล่อง Portfolio Overview<br>
6. ทำ Challenge แล้วบันทึกเป็น Item
   • ดูโจทย์ในกล่อง Challenge Booth (ชื่อ, คำอธิบาย, ขั้นตอน, Evidence prompt) แล้วลงมือทำ<br>
   • ไปที่ Import Portfolio Item วาง JSON ของ Item ในช่องซ้าย กดปุ่ม Import<br>
   • ช่องขวา (Review & Save) จะขึ้นมา กรอก What I did, What I learned, Challenge, Next step ให้ครบ 4 ช่อง ใส่ Evidence เพิ่มได้ (บรรทัดละ 1 ลิงก์)<br>
   • เลือก Portfolio ปลายทางใน Save to portfolio แล้วกด Save to Server<br>
   • รีเฟรชจะเห็น Item ในการ์ดของ Portfolio<br>
7. ส่งออก Portfolio
   • เลือก Portfolio แล้วกด Export My Portfolio จะได้ไฟล์ my-portfolio.json<br>
