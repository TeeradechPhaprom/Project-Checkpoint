เว็บสร้าง Portfolio ส่วนตัว กรอกโปรไฟล์และผลงาน แล้วบันทึก/โหลดข้อมูลด้วย localStorage

## วิธีเปิดเว็บ
1. Clone โปรเจกต์: `git clone https://github.com/TeeradechPhaprom/Project-Checkpoint.git`
2. เปิด `index.html` ด้วย Live Server (หรือดับเบิลคลิกเปิดในเบราว์เซอร์)

## วิธีทดลองใช้
1. กรอกฟอร์ม Profile และ Items แล้วกด Add Item
2. กด Save
3. Refresh หน้าเว็บ
4. กด Load ข้อมูลต้องกลับมาครบ
